My Project

Final Project ko sa CC102 - Console Based Game in Java

Number Guessing Game

Simple console game na ginawa ko gamit Java. Manghuhula si user ng number 1-100 na naisip ni computer. Gumamit ako ng Random, Scanner, Loop at If-else.

How it works:

  • Computer pipili ng secret number
  • User mag-guess hanggang makuha
  • Sasabihin kung too high or too low
  • Bibilangin ilan tries bago nahulaan

Source Code:


import java.util.Scanner;
import java.util.Random;

public class NumberGuessingGame {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        Random random = new Random();

        // welcome
        System.out.println("Welcome to Number Guessing Game!");
        System.out.println("Gawa ni Jasper Chavoso - BSIT 1-A");
        System.out.println("-------------------------------");

        System.out.print("Anong pangalan mo? ");
        String name = sc.nextLine();

        // pipili si computer ng number
        int secret = random.nextInt(100) + 1;
        int hula = 0;
        int tryCount = 0;

        System.out.println("Hi " + name + "! Nag-isip ako ng number 1 to 100.");

        while (hula != secret) {
            System.out.print("Hula mo: ");
            hula = sc.nextInt();
            tryCount++;

            if (hula < secret) {
                System.out.println("Masyadong mababa, taasan mo pa!");
            } else if (hula > secret) {
                System.out.println("Masyadong mataas, babaan mo!");
            } else {
                System.out.println("Galing! Nahulaan mo " + name + "!");
                System.out.println("Naka " + tryCount + " tries ka.");
            }
        }
        sc.close();
    }
}
